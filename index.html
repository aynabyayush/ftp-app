Full-Featured Protocol Toolset

Everything needed to turn an Android device into a reliable network storage node and remote file explorer.

Embedded Server Daemon

Powered by Apache FtpServer and Apache MINA. Run a fully autonomous FTP host on Wi-Fi or Personal Hotspot with configurable ports, user credentials, or anonymous access.

Real-Time Sync Engine

Automate local-to-remote folder mirroring. Configure interval triggers (every 15m, hourly, daily, or custom minutes) that run smoothly in the background via Android foreground services.

Multi-Volume & ZIP Engine

Access internal memory and mounted MicroSD cards directly. Compress multi-file folders to standard ZIP archives on-device for streamlined single-stream network transfers.

Screen-Off WakeLock Handling

Prevents transfers from dropping when the screen turns off by leveraging CPU WakeLocks and Wi-Fi Locks that maintain active network sockets through aggressive OS battery optimizations.

Quick Start

How To Connect & Transfer

01

Host Local FTP

Open FTPApp, select your shared directory, and tap Start Server. Connect your PC or Mac to the displayed URL directly over Wi-Fi.

02

Connect to Remote Host

Tap + Add Server, input target host IP and port, and browse remote directories in customizable List or Grid layouts.

03

Automate Backups

Set up a folder sync profile to auto-upload camera rolls, downloads, or documents to remote storage without manual intervention.

FOR DESKTOPS

How To Access Your Server On PC

Once the FTP daemon is running on your Android device, mount and browse your storage from any desktop or mobile client on the same network.

Windows

File Explorer

Open File Explorer (Win + E), paste your endpoint into the address bar, and press Enter to browse natively.

ftp://192.168.1.104:2121
macOS

Finder Connect

In Finder, press Cmd + K to open Connect to Server, enter the URL, and select Guest / Registered User.

ftp://192.168.1.104:2121
Third-Party Clients

FileZilla / WinSCP

Enter the host IP in Host, your specified port (default 2121) in Port, and choose Passive Mode (PASV) for optimal transfers.

Host: 192.168.1.104 • Port: 2121
CLI & Scripts

Terminal & cURL

Quickly query, download, or script automated pushes using standard command line protocol tools without installing external software.

curl -u user:pass ftp://192.168.1.104:2121/
