Embedded Server Daemon

Real-Time Sync Engine

Quick Start

How To Connect & Transfer

01

Host Local FTP

Open FTPApp, select your shared directory, and tap Start Server. Connect your PC or Mac to the displayed URL directly over Wi-Fi.

02

Connect to Remote Host

Tap + Add Server, input target host IP and port, and browse remote directories in customizable List or Grid layouts.

03

Automate Backups

Set up a folder sync profile to auto-upload camera rolls, downloads, or documents to remote storage without manual intervention.

For Desktops

How To Access Your Server On PC

Once the FTP daemon is running on your Android device, mount and browse your storage from any desktop or mobile client on the same network.

Windows

File Explorer

Open File Explorer (Win + E), paste your endpoint into the address bar, and press Enter to browse.

ftp://192.168.1.104:2221
macOS

Finder Connect

In Finder, press Cmd + K to open Connect to Server, enter the URL, and select Guest / Registered User.

ftp://192.168.1.104:2221
Third-Party

FileZilla / WinSCP

Enter host IP in Host, port (default 2221) in Port, and choose Passive Mode (PASV) for optimal transfers.

Host: 192.168.1.104 • Port: 2221
CLI & Scripts

Terminal & cURL

Quickly query, download, or script automated pushes using standard command line protocol tools without installing external software.

curl -u user:pass ftp://192.168.1.104:2221/
